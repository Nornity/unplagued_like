# Последний колокол · The Last Bell

3D-игра от первого лица на Godot 4: совместно очистите три деревни от чумы и исцелите девять жителей. Проект рассчитан на Windows и кооператив до четырёх игроков.

## Важно про EXE

В репозитории лежит полный проект Godot и готовый Windows Export Preset. **Скомпилированного `TheLastBell.exe` сейчас нет:** в среде разработки нет Godot и Windows export templates, а загрузка движка заблокирована. Я не буду выдавать исходники за готовый EXE.

Чтобы получить EXE на Windows:

1. Установите Godot **4.7.2 Standard** и Windows export templates той же версии.
2. Откройте `project.godot` в Godot.
3. Выберите **Project → Export → Windows Desktop → Export Project**; выходной файл — `release/TheLastBell.exe`.
4. Либо запустите `build_windows.bat` из каталога проекта, если `godot` доступен в `PATH`.

На Linux с установленными Godot 4.7.2 и Windows export templates можно выполнить `./build_windows.sh`. Чтобы выбрать другой бинарник Godot, задайте `GODOT_BIN=/path/to/godot`. В GitHub Actions также добавлен workflow `.github/workflows/windows-build.yml`: после отправки проекта в GitHub его можно запустить вручную и скачать EXE из артефактов запуска.

## Запуск проекта

Откройте `project.godot` в Godot 4.7.2 и нажмите **F6/F5**. Проект использует встроенные процедурные 3D-модели, поэтому внешние ассеты и плагины не нужны.

## Кооператив

- В меню нажмите **Создать игру** — запустится сервер и будет показан LAN-IP.
- Остальные игроки вводят этот IP и нажимают **Подключиться**.
- До 4 игроков; сетевой режим ENet, UDP-порт **24560**.
- Для игры через интернет хосту нужно разрешить/пробросить UDP 24560 на роутере. Автоматического matchmaking/relay-сервера нет.

## Управление

- **WASD** — движение; **мышь** — обзор.
- **Shift** — бег; **Space** — прыжок.
- Наведитесь на заражённого жителя и нажмите **F** или **ЛКМ**, чтобы применить травяное противоядие.
- **Esc** — отпустить курсор; нажмите ЛКМ, чтобы снова захватить его.

## Состав

- `project.godot` — настройки проекта.
- `scenes/main.tscn` — стартовая сцена.
- `scripts/main.gd` — процедурный мир, деревни, сетевая сессия, цели и интерфейс.
- `scripts/survivor.gd` — FPS-контроллер, камера, спрей-противоядие и синхронизация игрока.
- `export_presets.cfg` — пресет сборки Windows EXE.
